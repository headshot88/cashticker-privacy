# Политика конфиденциальности CashTicker **Дата вступления в силу: 1 октября 2026 года** Настоящая Политика конфиденциальности описывает порядок обработки информации мобильным приложением **CashTicker**, разработанным **RGS — Reutov Game Studio**. Мы стараемся минимизировать обработку пользовательских данных. CashTicker разработан таким образом, чтобы основная информация пользователя хранилась непосредственно на его устройстве. ## 1. Какие данные использует CashTicker CashTicker позволяет пользователю самостоятельно вводить и сохранять: - сумму дохода; - сумму расходов; - выбранную валюту; - финансовые цели; - настройки приложения; - настройки уведомлений. Эти данные используются исключительно для работы функций CashTicker, включая расчёт денежного потока, целей, режимов «Понты» и «АнтиПонты», виджета и живых обоев. **RGS — Reutov Game Studio не получает и не хранит введённые пользователем суммы доходов, расходов и финансовых целей на своих серверах.** CashTicker не требует регистрации или создания учётной записи. ## 2. Локальное хранение данных Основные пользовательские данные CashTicker сохраняются локально на устройстве пользователя. Приложение не использует собственный облачный сервер для хранения введённых финансовых данных. Данные сохраняются до тех пор, пока пользователь не изменит или не удалит их, не очистит данные приложения средствами операционной системы либо не удалит приложение. В зависимости от настроек операционной системы Android некоторые данные приложения могут участвовать в системном резервном копировании, выполняемом самой платформой Android. Такое резервное копирование регулируется настройками устройства и политиками соответствующей платформы и не контролируется RGS — Reutov Game Studio. ## 3. Подключение к Интернету и курсы валют CashTicker может использовать подключение к Интернету для получения актуальных курсов валют. Для получения курсов приложение обращается к публичным сервисам **Банка России**. При таком сетевом запросе сервер Банка России может автоматически получать стандартную техническую информацию сетевого соединения, например IP-адрес устройства. Обработка такой информации осуществляется соответствующим сервисом согласно его собственным правилам. Введённые пользователем данные о доходах, расходах и финансовых целях при запросе валютных курсов **не передаются**. Полученные курсы могут сохраняться локально на устройстве для уменьшения количества сетевых запросов. ## 4. Уведомления и вибрация CashTicker может использовать системные уведомления Android для напоминания о достижении установленной пользователем финансовой цели. Для этого приложение может запрашивать разрешение на отправку уведомлений и использование вибрации. Пользователь может отключить уведомления в настройках приложения или в системных настройках Android. Информация об установленной цели используется только для локального расчёта времени уведомления и не передаётся на серверы RGS — Reutov Game Studio. ## 5. Виджеты и живые обои CashTicker содержит функции виджета домашнего экрана и живых обоев Android. Для отображения актуальной информации эти функции получают необходимые значения из локального хранилища CashTicker на устройстве. Эта информация не отправляется разработчику. Следует учитывать, что информация, отображаемая пользователем на виджете или живых обоях, может быть видна другим людям, имеющим физический доступ к экрану устройства. ## 6. Персональные данные CashTicker не требует от пользователя указывать: - имя; - номер телефона; - адрес электронной почты; - адрес проживания; - платёжные реквизиты; - данные банковских карт. Приложение не предназначено для получения доступа к банковским счетам пользователя и не осуществляет банковские или инвестиционные операции. ## 7. Аналитика и реклама В текущей версии CashTicker: - отсутствует сторонняя реклама; - отсутствуют рекламные SDK; - отсутствуют системы пользовательской аналитики; - отсутствуют системы отслеживания пользователя; - введённые пользователем финансовые данные не используются для рекламных целей. Если в будущих версиях приложения будут добавлены аналитические, рекламные или иные сервисы, способные изменять порядок обработки данных, настоящая Политика конфиденциальности будет обновлена. ## 8. Передача данных третьим лицам RGS — Reutov Game Studio не продаёт и не передаёт введённые пользователем данные о доходах, расходах и финансовых целях третьим лицам. Единственным внешним сетевым взаимодействием, необходимым для текущей функциональности приложения, является получение публичной информации, например курсов валют. ## 9. Безопасность CashTicker использует принцип минимизации данных и по возможности хранит пользовательскую информацию непосредственно на устройстве. Поскольку приложение не использует собственную серверную базу данных для хранения финансовой информации пользователя, RGS — Reutov Game Studio не располагает серверной копией этих данных. Безопасность локально сохранённых данных также зависит от безопасности самого устройства пользователя и настроек операционной системы. ## 10. Хранение и удаление данных Поскольку основная пользовательская информация хранится локально, пользователь может удалить её: - изменив или удалив соответствующие данные в CashTicker; - очистив данные приложения через настройки Android; - удалив приложение с устройства. CashTicker не использует пользовательские аккаунты, поэтому отдельная процедура удаления учётной записи не требуется. ## 11. Дети CashTicker не предназначен специально для детей и не содержит функций, направленных на сознательный сбор персональных данных несовершеннолетних. ## 12. Изменения Политики конфиденциальности Настоящая Политика может обновляться при изменении функциональности CashTicker, законодательства или требований платформ распространения приложений. Актуальная версия Политики конфиденциальности всегда будет доступна по той же публичной ссылке. ## 13.
